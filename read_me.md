# Линейная регресси для предсказания логарифма цены на Gradio

Веб-приложение на Gradio для предсказания логарифма цены дома с помощью обученной модели линейной регрессии

## Структура проекта

```text
my_project/
├── app/
│   ├── __init__.py
│   ├── model.py              #бизнес-логика
│   └── app_regression.py     #интерфейс Gradio и обработчики
├── models/
│   └── LinReg_sklern_ver_1.9.1__pickle_ver_4.0.pkl # модель
├── data/
│   └── subsample_9.csv #исходные данные
├── ...
```


## Запуск

### 1. Про виртуальное окружение в README.md
[README.md](README.md)



### 2. Запуск приложения

Из корня проекта

```bash
python -m app.app_regression
```

В терминале появится:

```text
* Running on local URL:  http://127.0.0.1:7860
```  
Чтобы открыть приложение, заходим в браузер и в адрессной строке пишем`http://127.0.0.1:7860`. Порт `:7860` может быть другим, нужно подставить тот, что было выведено в терминате!!!  


## Как сохранить модель из Jupyter Notebook

После обучения линейной регрессии(`lin_reg`) пишем следующий код:

```python
import pickle
import sklearn

pickle.dump(lin_reg, open(f"models/LinReg_sklern_ver_{sklearn.__version__}__pickle_ver_{pickle.format_version}.pkl", "wb",),)
```

- `lin_reg` - обученная ЛР `LinearRegression`
- `X` - признаки
- `models/` - папка куда модель сохранится
